# my-first-project

Git・GitHubの使い方を学ぶための、はじめてのプロジェクトです。

## 概要

このリポジトリは、バージョン管理やGitHubでの開発フローに慣れることを目的とした練習用プロジェクトです。
コミット、ブランチ運用、プルリクエストの作成といった基本的な流れをここで試していきます。

## 目的

- Gitの基本操作（clone、commit、push、pull など）に慣れる
- ブランチを使った開発フローを体験する
- プルリクエストを通じた変更の管理を学ぶ

## はじめかた

```bash
git clone <このリポジトリのURL>
cd my-first-project
```

## ライセンス

特に定めていません。
